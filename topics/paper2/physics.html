    🖨️ Printable One-Page Quick Revision Sheets

    High-density exam-eve cheat sheets covering all formulas, universal logic gate tables, semiconductor comparisons, and PYQ traps.

    Sheet 1: Digital Electronics & Universal Gates (Highest Yield)

    • • AND: Y = A·B (1 only if all 1) | OR: Y = A+B (1 if any 1) | NOT: Y = A'
    • • NAND: Y = (A·B)' (1 if ANY input is 0 — Sep 2025 Q11) | NOR: Y = (A+B)' (1 ONLY if ALL inputs are 0)
    • • XOR: Y = A⊕B = A'B + AB' (Odd 1s / Inequality detector, min 2 inputs — Sep 2025 Q5)
    • • XNOR: Y = (A⊕B)' = AB + A'B' (Equality / Coincidence detector)
    • • Universal Gate Counts [NOT, AND, OR, XOR, XNOR]: NAND = [1, 2, 3, 4, 5] | NOR = [1, 3, 2, 5, 4]
    • • De Morgan's Laws: (A+B)' = A'·B' (Aug 2021 Q42) and (A·B)' = A'+B'
    • • Key Simplifications: A + A'B = A + B | A + AB = A | AC + ABC = AC (1 gate)
    • • Combinational (No Memory): Half Adder (S=A⊕B, C=AB), Full Adder (1 HA + 3 FA for 4-bit adder), BCD Adder (256 − 100 = 156 invalid states — Jun 2023 Q130), MUX, Encoder, Decoder (Jun 2023 Q141).
    • • Sequential (Memory): SR (S=R=1 invalid), JK (J=K=1 toggles), D (Q_next=D), T (toggles on T=1, holds on T=0 — Aug 2021 Q19). MOD-N needs ⌈log₂ N⌉ FFs. n-bit Johnson counter = 2n states.

    Sheet 2: Modern Physics, Lasers, EM Waves & Semiconductors

    • • EM Spectrum (f ↑, λ ↓): Radio → Microwave (Cellular/TV — Sep 2025 Q64) → IR (Unguided — Aug 2021 Q57) → Visible (400–700 nm) → UV → X-Rays (1 nm to 10⁻³ nm via electron bombardment — Sep 2025 Q68) → Gamma.
    • • Wave & Optics PYQs: Wavelength λ = v × T (Feb 2024 Q183); Sine wave params = Peak Amplitude, Frequency, Phase (Feb 2024 Q184); Retardation plate phase shift = Double Refraction (Jun 2023 Q109); Polarisation = Transverse waves only (Jun 2023 Q169).
    • • Laser PYQs: Ground state lifetime = Infinity (Jun 2023 Q128); CO₂ laser = Vibrational states (Jun 2023 Q115).
    • • Photoelectric & Matter Waves: hf = φ + eV₀ (V₀ depends on f, NEVER intensity!); λ = h/mv = 1.227/√V nm (electron).
    • • Nuclear Physics: N = N₀(1/2)ⁿ; α (ΔZ=−2, ΔA=−4), β⁻ (ΔZ=+1, ΔA=0); 1 u = 931.5 MeV.
    • • Semiconductors & ROM PYQs: Si E_g=1.1 eV (V_0=0.7V), Ge E_g=0.72 eV (V_0=0.3V); N-type (P, As, Sb) & P-type (B, Al, Ga, In) are both Electrically Neutral! EPROM erased by UV sets all bits to 1 (Sep 2025 Q61); EEPROM erased electrically (Sep 2025 Q65).

    Sheet 3: Electricity, Electrostatics & Capacitance

    • • Charge & Current: q = ±ne (1 C = 6.25×10¹⁸ e⁻); I = q/t = neAv_d (Scalar!).
    • • Ohm's Law & Stretching: V = IR; R = ρL/A. Stretching to n×L (volume constant) ⇒ R' = n²R; ρ unchanged!
    • • Kirchhoff's Laws: KCL (ΣI = 0) = Conservation of Charge; KVL (ΣΔV = 0) = Conservation of Energy.
    • • Power & Bulbs: P = VI = I²R = V²/R; 1 kWh = 3.6×10⁶ J. In SERIES, lower-wattage bulb (higher R) glows brighter! Fuse wire = High ρ, Low melting point (Pb-Sn alloy).
    • • Electrostatics & Capacitors: F = kq₁q₂/(Kr²); Inside hollow conductor E = 0, V = kQ/R (constant). Parallel plate C = Kε₀A/d; Series 1/C_s = Σ(1/C_i); Parallel C_p = ΣC_i; Energy U = ½CV² = Q²/(2C). DRAM stores bits in leaky capacitors.

    Sheet 4: Magnetism, EMI, AC, Vectors & SHM

    • • Magnetic Fields: 1 T = 10⁴ Gauss; Wire B = μ₀I/(2πr); Coil B = μ₀NI/(2R); Solenoid B = μ₀nI (independent of radius).
    • • Magnetic Force: F = qvB sinθ (Work done = 0, KE constant; r = mv/qB); Wire F = BIL sinθ; Parallel same-direction currents ATTRACT.
    • • EMI & AC: E = −NΔΦ/Δt; Lenz's law = Conservation of Energy; Induced charge q = NΔΦ/R (independent of Δt!). V_rms = V₀/√2 (220V RMS ⇒ 311V peak). X_L = 2πfL, X_C = 1/(2πfC) (blocks DC!). Transformer V_s/V_p = N_s/N_p = I_p/I_s (AC only, laminated soft iron core reduces eddy currents).
    • • SHM, Vectors & Dimensions (2021–2025 PYQs): SHM x = A sin(2πt/T) (Sep 2025 Q76); Vector identity ∇·(∇×V) = 0 (Aug 2021 Q2) & ∇×(∇φ) = 0; Normal n̂ = ∇f/|∇f| (Jun 2023 Q161); [RC] = [L/R] = [√LC] = [T].
