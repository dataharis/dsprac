1. SQL Command Classification & DELETE vs. TRUNCATE vs. DROP

CategoryCommandsKey DSSSB Exam Rule
DDL (Schema)CREATE, ALTER, DROP, TRUNCATE, RENAMEAuto-commits; modifies System Catalog (PYQ 2017 Q.105, Q.186).
DML (Row Data)INSERT, UPDATE, DELETEModifies tuples; can be rolled back (PYQ 2025 Q.2, Q.5).
DQL (Query)SELECTRetrieves data (grouped under DML in 4-category ISO model).
DCL (Security)GRANT, REVOKEControls permissions (WITH GRANT OPTION, CASCADE).
TCL (Transaction)COMMIT, ROLLBACK, SAVEPOINTManages ACID atomicity & durability (PYQ 2017 Q.187).
DELETE vs TRUNCATE vs DROPDELETE: DML, allows WHERE, rollbackable · TRUNCATE: DDL, deletes all rows fast, keeps schema, NO WHERE · DROP: DDL, destroys data + schema!

2. Logical Execution Order, Operator Precedence & NULL Rules

TopicExact Rule / Formula
Logical Execution Order1. FROM/JOIN → 2. WHERE → 3. GROUP BY → 4. HAVING → 5. SELECT → 6. DISTINCT → 7. ORDER BY → 8. LIMIT
Logical PrecedenceNOT > AND > OR (PYQ 2017 Q.171); Arithmetic *, / > +, -
WHERE vs HAVINGWHERE filters rows before GROUP BY (NO aggregates allowed!); HAVING filters groups after GROUP BY (aggregates allowed).
3-Valued NULL LogicNULL = NULL → UNKNOWN; NULL IS NULL → TRUE (PYQ 2025 Q.17); X NOT IN (1, NULL) → 0 rows!

3. Aggregate Functions, Joins, Subqueries & Built-In Functions

ConceptExam Trap & Behavior
COUNT(*) vs COUNT(col) vs AVG(col)COUNT(*) counts all rows including NULLs; COUNT(col) & AVG(col) ignore NULLs (AVG = SUM(col)/COUNT(col)). Empty table: COUNT → 0, SUM/AVG/MIN/MAX → NULL.
JOIN Row CountsINNER: matches only · LEFT: all left + NULL right · FULL: all both · CROSS: $|L|\times|R|$ rows (PYQ 2024 Q.81).
Subquery Quantifiers= SOME / = ANY $\equiv$ IN (PYQ 2017) · <> ALL $\equiv$ NOT IN · > ANY $\equiv$ > MIN · > ALL $\equiv$ > MAX.
Set OperationsUNION (deduplicates) vs UNION ALL (keeps duplicates); INTERSECT ($R \cap S$); EXCEPT / MINUS ($R - S$, PYQ 2024 Q.70).
Built-In Functions (PYQ 2024)|| concatenates strings (Q.71); LIKE uses % (0+ chars) & _ (1 char, Q.85); CEILING(14.2)=15, CEILING(-14.2)=-14 (Q.61); GETDATE() & DATEDIFF() (Q.4, Q.15); SUBSTR is 1-indexed!
SQL:1999 View RuleORDER BY is disallowed inside CREATE VIEW (PYQ 2025 S1 Q.11).

  • Ramez Elmasri & Shamkant B. Navathe: Fundamentals of Database Systems (7th Edition, Pearson) — Reference for SQL DDL constraints (DROP SCHEMA RESTRICT) and views.
