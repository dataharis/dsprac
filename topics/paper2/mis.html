📌 Sheet 1: Golden Exam Formulas & Exact Definitions

  • 5 Components of IS/MIS (2023 Q.60): Hardware + Software + Data + Procedures + People ('Education' is NOT a component!)
  • 3 Subsystems of DSS (2021 Q.76): Database (DBMS) + Model Base (MBMS) + Dialog/User Interface (DGMS)
  • Expert System Core Formula: Expert System = Knowledge Base (IF-THEN Rules + Facts) + Expert System Shell (Inference Engine + Explanation Facility + Working Memory + UI)
  • Herbert Simon's 4 Decision Phases: 1. Intelligence → 2. Design → 3. Choice → 4. Implementation (+ Bounded Rationality / Satisficing)
  • Nonaka & Takeuchi SECI Spiral: Socialization (Tacit→Tacit) → Externalization (Tacit→Explicit) → Combination (Explicit→Explicit) → Internalization (Explicit→Tacit)
  • Meyer & Zack KM Refinery Cycle (2023 Disc2 Q.18): Acquisition → Refining (Cleansing/Indexing/Standardizing) → Storage/Retrieval → Distribution → Presentation/Use
  • MYCIN Certainty Factor: CF(H, E) = (MB - MD) / (1 - min(MB, MD)) ranging from -1.0 to +1.0
  • Expected Value of Information: EVPI = Expected Payoff WITH Info − Expected Payoff WITHOUT Info
  • Customer Churn Rate: (Customers Lost in Period / Total Customers at Start) × 100
  • Richard Mason's PAPA Ethics (1986): Privacy, Accuracy, Property, Accessibility
  • Feasibility Study Framework (TELOS): Technical, Economic, Legal, Operational, Schedule

📌 Sheet 3: OLAP Operations, Changeover Strategies & Acronym Master Dictionary

5 OLAP Cube Operations

  • Roll-Up: Aggregate up hierarchy (City → Country, Day → Year).
  • Drill-Down: Break summary into fine detail (Year → Month → Day).
  • Slice: Fix 1 dimension to a single value (produces a 2D slice).
  • Dice: Filter 2 or more dimensions to produce a smaller 3D sub-cube.
  • Pivot (Rotate): Swap rows and columns axes for alternative view.

4 System Changeover Strategies

  • Parallel Conversion: Old + New run together. Safest (Lowest Risk), Most Expensive.
  • Direct Cutover (Plunge): Abrupt switch. Cheapest, Highest Risk.
  • Pilot Conversion: Test in 1 branch/dept first, then roll out nationwide.
  • Phased Conversion: Roll out module-by-module (Payroll Q1 → Inventory Q2).

High-Yield Exam Acronyms

  • MBMS / DGMS: Model Base / Dialog Generation Mgmt System (DSS)
  • ANSI X.12 / EDIFACT: B2B Electronic Data Interchange (2021 Q.120)
  • EDA: Exploratory Data Analysis — John Tukey (2024 Q.2)
  • CLV & VMI: Customer Lifetime Value & Vendor-Managed Inventory
  • RPO / RTO: Recovery Point / Recovery Time Objective
