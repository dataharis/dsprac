4. Top 12 DSSSB TGT Exam Traps to Avoid

  • ARP Scope (2025 Q.20): ARP Request is Broadcast (`FF:FF:FF:FF:FF:FF`), but ARP Reply is Unicast.
  • TCP Termination (2025 Q.19): `FIN` closes gracefully (4-way); `RST` (Reset) aborts immediately.
  • Selective Repeat (2025 Q.1): Receiver buffers out-of-order frames (Go-Back-N discards them).
  • Asymmetric Decryption (2025 Q.6): Encrypted with Recipient's Public Key → Decrypted ONLY with Recipient's Private Key.
  • Coaxial Ratings (2024 Q.89): Coaxial cables are categorized by Radio Government (RG) ratings.
  • Port Numbers: FTP (`20` Data, `21` Control), SSH (`22`), Telnet (`23`), SMTP (`25`/`587`), DNS (`53`), DHCP (`67`/`68`), TFTP (`69`), HTTP (`80`), POP3 (`110`/`995`), NTP (`123`), IMAP (`143`/`993` — 2023 Q.15), SNMP (`161`/`162`), HTTPS (`443`).
  • Portless Protocols: ARP, RARP, IP, ICMP (`ping`), IGMP, and Ethernet operate at L2/L3 and have NO port numbers.
  • Cellular Speed Order (2021 Q.88): `GSM < GPRS < EDGE < LTE`.
