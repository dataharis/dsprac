11. Printable One-Page Quick Revision Sheets & High-Yield Differences

            
Rapid last-minute revision of HTML tags, CSS Box Model & Specificity, JS Output Rules, XML vs HTML/JSON, PHP GET vs POST, Cookies vs Sessions, and .NET CLR/CTS/CLS.

          

          
        


        

          
          

            
Sheet 1: HTML & HTML5 High-Yield Tags & Traps

            
    
              
  • <HEAD> (2024 Q.46): Container for metadata (<title>, <meta>, <link>, <style>).
    • 
              
  • <h1> to <h6> (2017 Q.195): <h1> is largest; <h6> is smallest.
    • 
              
  • <HR> Trap (2024 Q.40): Valid attributes: ALIGN, WIDTH, SIZE, NOSHADE. SHADE is INVALID!
    • 
              
  • <BODY> Link Colors (2024 Q.28): LINK (unvisited), VLINK (visited), ALINK (active link being clicked).
    • 
              
  • <colgroup span="n"> (2021 Q.41): Uses span (while <td>/<th> use colspan and rowspan).
    • 
              
  • readonly vs. disabled: readonly IS submitted with the form; disabled is NOT submitted.
    • 
            

          


          
          

            
Sheet 2: CSS3 Box Model, Specificity & PYQ Rules

            
    
              
  • Specificity Hierarchy: !important > Inline (1,0,0,0) > #id (0,1,0,0) > .class/:hover/[attr] (0,0,1,0) > element/::before (0,0,0,1) > * (0,0,0,0).
    • 
              
  • Combinators: div p (descendant), div > p (direct child), h1 + p (adjacent sibling), h1 ~ p (general sibling).
    • 
              
  • Box Model Order (Inside Out): Content $
ightarrow$ Padding $
ightarrow$ Border $
ightarrow$ Margin.
    • 
              
  • HSL Model (2021 Q.90): Hue ($0^\circ	ext{–}360^\circ$), Saturation ($0	ext{–}100\%$), Lightness ($0	ext{–}100\%$).
    • 
              
  • CSS Transitions (2023 Q.2) & Sass (2023 Q.42): Transitions animate properties smoothly; Sass is a CSS extension language.
    • 
            

          


          
          

            
Sheet 3: JavaScript Coercion, DOM & Event Propagation

            
    
              
  • Type Quirks: typeof null === "object"; typeof NaN === "number"; NaN === NaN is false.
    • 
              
  • + vs. - Coercion: 2 + 3 + "5" === "55"; "5" + 2 + 3 === "523"; "10" - 4 === 6.
    • 
              
  • DHTML & BOM (Sep 2025 PYQs): element.style.color = "red" (Q.42); window.resizeTo(w, h) (Q.55).
    • 
              
  • Event Propagation: Default is Bubbling (inner $
ightarrow$ outer); 3rd arg true enables Capturing (outer $
ightarrow$ inner).
    • 
              
  • Web Storage: localStorage persists permanently; sessionStorage clears when tab closes.
    • 
            

          


          
          

            
Sheet 4: XML Rules, DTD vs. XSD & DOM vs. SAX

            
    
              
  • Well-Formed XML: Exactly 1 Root Element, case-sensitive tags, all tags closed, proper nesting, quoted attributes.
    • 
              
  • Naming Rules (2024 Q.54): Start with letter or _; cannot start with digit or xml; no spaces allowed.
    • 
              
  • DTD Element Syntax (2023 Q.15): <!ELEMENT element-name category>. Quantifiers: + (1+), * (0+), ? (0 or 1).
    • 
              
  • DOM vs. SAX Parser (2023 Q.39): DOM loads full XML tree into RAM; SAX is event-based stream parser (low memory).
    • 
              
  • Tabular Data Control (2023 Q.56): Microsoft ActiveX control for sorting/binding data files into HTML.
    • 
            

          


          
          

            
Sheet 5: PHP Superglobals, Sorting & State Management

            
    
              
  • String vs. Math: . is string concatenation ("10"."20" = "1020"); + is numeric addition ("10"+"20" = 30).
    • 
              
  • Array Sorting (Sep 2025 Q.44): asort() sorts associative array ascending by value preserving keys; ksort() sorts by key; sort() re-indexes keys.
    • 
              
  • $_GET vs. $_POST: $_GET sends in URL (~2048 chars, bookmarkable); $_POST sends in HTTP body (secure for passwords & file uploads).
    • 
              
  • Cookies vs. Sessions: Cookies stored on Client Browser (~4 KB, setcookie()); Sessions stored on Web Server (session_start(), $_SESSION).
    • 
            

          


          
          

            
Sheet 6: Microsoft .NET (2002), CLR, ASP.NET & VB.NET

            
    
              
  • .NET Architecture: Launched by Microsoft in 2002 (2023 Q.12). Source $
ightarrow$ MSIL/CIL $
ightarrow$ CLR (Virtual Machine — 2021 Q.167) $
ightarrow$ JIT Compiler $
ightarrow$ Native Code.
    • 
              
  • CTS vs. CLS: CTS standardizes Value Types (Stack) & Reference Types (Heap); CLS is subset of rules for cross-language interoperability.
    • 
              
  • ASP.NET PYQs (2017): Response.Output.Write() = formatted output (Q.118); Default session = InProc (Q.172); Forms Auth = System.Web.Security (Q.174); App/Session events = Global.asax (Q.193).
    • 
              
  • VB.NET Traps: Dim a(4) has 5 elements (0..4); \ is integer division; Sub returns nothing vs Function returns value; FileOpen uses Append (2021 Q.70); Constructors (Sub New / C#) have NO return type (2023 Q.64).
