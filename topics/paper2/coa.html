RISC (Reduced Instruction Set Computer — ARM, RISC-V, MIPS)

• Fixed-length 32-bit instructions • Single-cycle execution (CPI ≈ 1) • Load/Store architecture (only LOAD/STORE access RAM) • Large register file (32+ regs) • Hardwired Control Unit.

CISC (Complex Instruction Set Computer — Intel x86, VAX, IBM 360)

• Variable-length instructions (1 to 15 bytes) • Multi-cycle execution • Memory-to-memory arithmetic allowed • Fewer architectural registers • Microprogrammed Control Memory (ROM).

1–4. Block Diagram, CPU Registers, Instruction Cycle & Addressing Modes

  • • CPU Registers: PC = Address of NEXT instruction; IR = Current instruction being decoded (PYQ 2024 Q.33); MAR $\to$ Unidirectional Address Bus; MDR $\leftrightarrow$ Bidirectional Data Bus; AC = Implied 1-address Accumulator (PYQ 2024 Q.30).
  • • Instruction Cycle: Fetch ($T_0: \text{MAR}\leftarrow\text{PC}$, $T_1: \text{MDR}\leftarrow M[\text{MAR}], \text{PC}\leftarrow\text{PC}+1$, $T_2: \text{IR}\leftarrow\text{MDR}$) $\to$ Decode $\to$ Effective Address $\to$ Execute. (Encode is NOT a phase — PYQ 2025 Q.88).
  • • Addressing Mode Memory Refs (Execute Phase): Immediate = 0 | Register = 0 | Direct = 1 | Register Indirect ($EA=\text{R1}$ — PYQ 2024 Q.27) = 1 | Memory Indirect ($EA=M[\text{Addr}]$ — PYQ 2021 Q.60) = 2.
  • • Special Modes: Indexed ($EA=\text{Base}+\text{XR}$) = Arrays; Base-Register = Program Relocation; PC-Relative ($EA=\text{PC}_{\text{next}}+\text{Offset}$) = Branches.

5–7. Logic Gates, Boolean Laws, Adders & Flip-Flops

  • • Universal Gates (NAND / NOR): NAND count for [NOT, AND, OR, XOR, XNOR] = [1, 2, 3, 4, 5]; NOR count for [NOT, OR, AND, XNOR, XOR] = [1, 2, 3, 4, 5].
  • • Boolean Laws: De Morgan: $(AB)' = A'+B'$, $(A+B)' = A'B'$. Absorption: $A + AB = A$, $A + A'B = A + B$. Consensus: $AB + A'C + BC = AB + A'C$.
  • • Adders: Half Adder ($S=A\oplus B, C=AB$, 5 NANDs); Full Adder ($S=A\oplus B\oplus C_{in}, C_{out}=AB+C_{in}(A\oplus B) = \mathbf{2\text{ HA} + 1\text{ OR}}$, 9 NANDs).
  • • Flip-Flops (1-Bit Storage): SR ($S=1,R=1$ Invalid); JK ($J=1,K=1$ Toggles $Q'(t)$, Master-Slave cures Race-Around); D ($Q^+=D$, Registers); T ($Q^+=T\oplus Q$, Counters, divides clock by $2^n$).

8–11. Memory Hierarchy, Cache Mapping, SRAM vs DRAM & DMA/Interrupts

  • • Chip Sizing (PYQ 2021 S3 Q.40): $2^k \times m \implies k$ Address lines, $m$ Data lines ($64\text{K}\times 8 = 2^{16}\times 8 \implies \mathbf{16\text{ Address}, 8\text{ Data}}$). Chip count $= \frac{\text{Target Capacity}}{\text{Chip Capacity}}$.
  • • SRAM vs DRAM: SRAM = 6-Transistor Flip-Flop (fast, L1/L2/L3 Cache, no refresh); DRAM = 1-Transistor + 1-Capacitor (Main RAM, needs periodic refresh — PYQ 2023 Q.49). EPROM = Erased by UV Light (PYQ 2025 Q.84).
  • • Cache Mapping ($N$-bit Addr, $2^c$ lines, $2^b$-byte block): Direct = [Tag(N-c-b) | Line(c) | Offset(b)]; Associative = [Tag(N-b) | Offset(b)]; $k$-Way Set Assoc ($2^s$ sets) = [Tag(N-s-b) | Set(s) | Offset(b)].
  • • Interrupts & DMA: Disabling interrupt = Masking (PYQ 2021 Q.153). DMA connects to System Bus (PYQ 2017 Q.178); Burst Mode transfers whole block continuously (PYQ 2024 Q.38); Cycle Stealing transfers 1 word per stolen cycle.

12–15. RISC vs CISC, Pipeline Hazards, Flynn's Taxonomy & Master Formulas

  • • RISC vs CISC (PYQ 2024 Q.25): RISC = Fixed instruction length, Load/Store, large register file, single-cycle, Hardwired CU. CISC = Variable length, memory operands, Microprogrammed Control ROM.
  • • Pipelining ($k$ stages, $n$ instructions): Total Cycles $= \mathbf{k + n - 1}$; Time $T = (k + n - 1)t_p$; Max Speedup $S_{\max} = k$.
  • • Pipeline Hazards: Structural (hardware conflict $\to$ Split I/D Cache), Data RAW (True dependency $\to$ Operand Forwarding), WAR/WAW (Name dependency $\to$ Register Renaming), Control (Branch $\to$ Prediction/Delayed Branch).
  • • Flynn's Taxonomy: SISD (Uniprocessor), SIMD (GPUs/Vectors), MISD (Systolic arrays), MIMD (Multi-core/SMP/Clusters).
