2. Top 15 DSSSB TGT DAA Formulas & Exam Traps

  1. 1D Array Length [PYQ 2021]: $U - L + 1$; Address $= B + (i - L)\times w$.
  2. 2D Array Size [PYQ 2021]: $(U_1 - L_1 + 1)(U_2 - L_2 + 1)$; Row-Major $= B + [(i-L_1)N + (j-L_2)]w$.
  3. Queue Using Stacks [PYQ 2017]: Minimum 2 Stacks required.
  4. Circular Queue Full / Count: Full: (rear + 1) % N == front; Count: (rear - front + N) % N + 1.
  5. Binary Search [PYQ 2021 & 2025]: Worst case $O(\log n)$; unsuccessful exit when End < Beg.
  6. Sorting Linked Lists [PYQ 2025]: Merge Sort is best ($O(n\log n)$ time, $O(1)$ list-merge space).
  7. Quick Sort vs Heap Sort [PYQ 2017 & 2021]: Quick Sort worst case is $\Theta(n^2)$ (on sorted input); Heap Sort is ALWAYS $O(n\log n)$.
  8. Stable Sorts [PYQ 2017]: Bubble, Insertion, Merge, Counting, Radix. (Selection, Quick, Heap are Unstable).
  9. Minimum Swaps Sort: Selection Sort performs at most $n - 1$ swaps ($O(n)$).
  10. Binary Tree Leaf Formula: $n_0 = n_2 + 1$; Strict $m$-ary tree: $L = (m - 1)I + 1$; NULL links $= N + 1$.
  11. AVL & Red-Black [PYQ 2021]: AVL $\text{BF} \in \{-1, 0, +1\}$ (LL/RR single, LR/RL double); RB max height $\le 2\log_2(n+1)$.
  12. Simple Graph [PYQ 2017 & 2021]: Max degree $= n - 1$; Max edges $= \frac{n(n-1)}{2}$; Pendant vertex has degree $1$.
  13. MST Edges: Always $V - 1$ edges ($E - V + 1$ edges removed); Prim's (dense) & Kruskal's (sparse, Union-Find).
  14. Shortest Paths [PYQ 2021]: Unweighted = BFS ($O(V+E)$); Non-negative = Dijkstra ($O(V^2)$); Negative = Bellman-Ford ($O(VE)$).
  15. Hashing Clustering: Linear Probing = Primary Clustering; Quadratic = Secondary Clustering; Double Hashing = Neither.
