🔥 Top 20 DSSSB TGT C Exam Traps (Must-Memorize!)

  1. Negative Modulo Sign [PYQ 2021]: Sign of a % b ALWAYS matches a (dividend): 7 % -3 = +1, -7 % 3 = -1.
  2. Relational Chaining [PYQ 2025]: 5 > 3 > 0 evaluates left-to-right as (5 > 3) > 0 → 1 > 0 → 1 (True)!
  3. Pre-Increment Division [PYQ 2021]: int k=8, v=8; k / ++v → 8 / 9 = 0.
  4. Octal Prefix Trap [PYQ 2023]: Leading 0 means Base-8 Octal: 017 = 1*8 + 7 = 15 (and 018 is a Compile Error!).
  5. Comments Do Not Nest [PYQ 2017]: /* ... /* ... */ ... */ is a syntax error at the second */.
  6. sprintf() Return Value [PYQ 2025]: Returns characters written excluding '\0' (sprintf(b, "Hello, World!") returns 13).
  7. printf() Return Value: Returns count of characters printed (printf("%d", printf("ABC")) prints ABC3).
  8. sizeof('A') vs sizeof(char): In C, character literal 'A' has type int (sizeof('A') == 4), while sizeof(char) == 1.
  9. sizeof(++x) Side Effect: Operand of sizeof is NOT evaluated at runtime; x does NOT increment!
  10. strcmp(s1, s2) Equality Trap: Returns 0 when equal! Use strcmp(a, b) == 0.
  11. Array Assignment Error [PYQ 2025]: char arr[6]; arr = "hello"; is a Compile Error (array name is non-modifiable).
  12. register Restrictions [PYQ 2017 & 2025]: Cannot be global, and cannot apply address-of & operator!
  13. Returning static Array [PYQ 2025]: Returning static int arr[5] from a function is safe; returning local auto array is a dangling pointer.
  14. Double Pointer [PYQ 2017 & 2023]: For p = &a; q = &p;, *q == &a and **q == a.
  15. Function Pointer Syntax [PYQ 2017]: int (*f)(int*); (parentheses around *f are mandatory).
  16. struct + union Size [PYQ 2021]: struct = sum of members (+ padding); union = largest member size.
  17. Unparenthesized Macro Trap: #define SQR(x) x*x makes SQR(3+2) = 3 + 2*3 + 2 = 11!
  18. typedef vs #define Pointer: typedef char* cp; cp a, b; (both pointers) vs #define dp char* (only a is pointer!).
  19. Shift vs Addition Precedence: + binds tighter than <<, so 1 << 2 + 1 = 1 << 3 = 8!
  20. Equality vs Bitwise Precedence: == binds tighter than &, so 6 & 4 == 4 = 6 & 1 = 0!
