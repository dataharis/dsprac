⚡ 20 Must-Memorize DSSSB TGT Linux & Unix Rapid-Fire Facts

1. Kernel PID = 0 (`swapper`/`sched`); `/etc/init` PID = 1 (TGT 2017 Q.107, Q.185).
2. BASH Prompt: Regular user = `$`; Superuser (`root`, UID 0) = `#` (TGT 2023 Q.9).
3. `-rwxr--r--` in octal is `744`; `-rwxr-xr-x` is `755` (TGT 2017 Q.184).
4. `chmod` requires 2 main arguments: `mode` and `filename` (TGT 2023 Q.20).
5. `script` command records a user's terminal login session into a file (TGT 2017 Q.119).
6. `touch` creates an empty 0-byte file or updates file timestamps (TGT 2017 Q.189).
7. `rm -r` recursively removes a directory and its contents; `rmdir` only removes empty dirs (TGT 2017 Q.188).
8. `rm doc*` deletes all files in current directory starting with `doc` (TGT 2023 Q.55).
9. `cat sample.txt | more` displays a file one page/screen at a time (TGT 2017 Q.183).
10. `ps` shows processes in current shell; `kill -s` sends specified signal (TGT 2017 Q.181, Q.182).
11. `getpid()` returns current process ID; `getppid()` returns parent PID (TGT 2025 Q.10).
12. Hard link (`ln`) shares the same Inode; Soft link (`ln -s`) creates a new Inode storing target path (TGT 2021 Q.168).
13. File Descriptors: `0 = stdin`, `1 = stdout`, `2 = stderr`; `2>&1` merges stderr into stdout.
14. `umask` Math: File default = `666 - umask`; Directory default = `777 - umask`.
15. Signals: `SIGHUP = 1`, `SIGINT = 2 (Ctrl+C)`, `SIGKILL = 9 (uncatchable)`, `SIGTERM = 15 (default kill)`.
16. `df` vs `du` vs `free`: `df` = partition free disk space; `du` = file/dir disk usage; `free` = RAM & Swap.
17. Modern vs Legacy Networking: `ip addr` replaces `ifconfig`; `ss` replaces `netstat`.
18. `vi` Editor Modes: Starts in Command Mode (`i` -> Insert Mode, `Esc` -> Command Mode, `:wq` save & quit, `:q!` quit without save).
19. Inode Contents: Stores UID, GID, mode (`rwx`), size, timestamps, and block pointers—but NEVER the filename!
20. Package Managers: Debian/Ubuntu uses `.deb` (`dpkg`, `apt`); Red Hat/Fedora uses `.rpm` (`rpm`, `yum`, `dnf`).
