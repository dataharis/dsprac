Top 10 Most Repeated DSSSB TGT Exam Traps

  1. Half Subtractor Borrow vs Carry: Half Adder Carry is $A \cdot B$, whereas Half Subtractor Borrow ($A - B$) is $A'B$ (2021 S2 Q.128).
  2. Tied-Input XOR vs XNOR: $B \oplus B = 0$ (2021 S2 Q.131), whereas $B \odot B = 1$.
  3. Minimum 2-Input Universal Gates: XOR needs 4 NAND or 5 NOR gates; XNOR needs 5 NAND or 4 NOR gates.
  4. Minterm vs Maxterm Bit Polarity: Minterm $m_5 (101_2) = AB'C$, whereas Maxterm $M_5 (101_2) = A' + B + C'$.
  5. Same Function vs Complement Conversion: If $F(A,B,C) = \Sigma m(0,2,4,5,6)$, then the same function in POS is $\Pi M(1,3,7)$, while the complement $F'$ in SOP is $\Sigma m(1,3,7)$.
  6. K-Map Gray Code Order: Row/Column headers MUST be 00, 01, 11, 10 (cells 2 and 3 are swapped, and rows 2 and 3 are swapped).
  7. 3-Variable Odd Function Equivalence: For ANY odd number of inputs ($n = 3, 5, \dots$), $A \oplus B \oplus C = A \odot B \odot C = \Sigma m(1,2,4,7)$.
  8. Ring vs Johnson Counter States: An $N$-bit Ring Counter has $N$ states; an $N$-bit Johnson (Twisted-Ring) Counter has $2N$ states (2021 S3 Q.35).
  9. Multivibrator Stable States: Bistable = 2 stable states (Flip-Flop); Monostable = 1 stable + 1 quasi-stable (One-shot, 2021 S2 Q.129); Astable = 0 stable states (Clock).
  10. Total Boolean vs Self-Dual Functions: Total functions of $n$ variables = $2^{2^n}$; Self-Dual functions = $2^{2^{n-1}}$.
