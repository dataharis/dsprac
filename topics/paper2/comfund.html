1–4. Generations, Block Diagram, CPU & Memory Hierarchy

  • • 5 Generations: 1st=Vacuum Tubes (ENIAC/EDVAC/UNIVAC) | 2nd=Transistors (IBM 1401) | 3rd=ICs (Kilby/Noyce, IBM 360) | 4th=VLSI Microprocessor (Intel 4004) | 5th=ULSI & AI (PARAM 8000).
  • • CPU Registers: PC = Next instruction address; IR = Current instruction being decoded (PYQ 2024 Q.33); MAR $\to$ Unidirectional Address Bus; MDR $\leftrightarrow$ Bidirectional Data Bus; AC = Implied 1-address accumulator (PYQ 2024 Q.30).
  • • Memory Speed Order: Registers > L1/L2/L3 SRAM Cache > DRAM (Capacitor, periodic refresh — PYQ 2023 Q.49) > Flash/EEPROM/EPROM (UV light erase — PYQ 2025 Q.84) > NVMe SSD > HDD > Magnetic Tape (Sequential — PYQ 2021 Q.26).
  • • Chip Sizing: $2^k \times m \implies k$ Address lines, $m$ Data lines ($64\text{K} \times 8 \implies 16$ Address, $8$ Data — PYQ 2021 Q.40).

5–8. I/O Devices, Storage, Software Types & OS Basics

  • • Readers: MICR (9-digit bank cheque code, Iron Oxide), OMR (shaded exam bubbles — PYQ 2021 & 2024), OCR (scanned text), Plotter (vector CAD output).
  • • Printers: Impact = Dot-Matrix (CPS — PYQ 2021 Q.29), Daisy Wheel, Line Printer. Non-Impact = Laser (Toner + Drum, PPM/DPI), Inkjet, Thermal.
  • • Translators & FOSS: Compiler (whole source $\to$ object — PYQ 2021 Q.123), Interpreter (line-by-line, Perl/Python — PYQ 2021 Q.15), Assembler (assembly $\to$ machine — PYQ 2024 Q.29), Linker, Loader. GIMP is Open-Source (PYQ 2025 Q.87).
  • • OS & Booting: Kernel = innermost memory-resident core (PYQ 2021 Q.155). POST = Power-On Self-Test in ROM BIOS/UEFI.

9–11. Internet Terminology, File Extensions & MS Word Shortcuts

  • • Internet & Email: HTTP (80), HTTPS (443), DNS (53), FTP (20/21), SMTP (25 — Send), POP3 (110), IMAP (143). BCC hides recipient addresses. Chrome DevTools = Ctrl+Shift+I / F12 (PYQ 2021 Q.140).
  • • File Extensions: Word (.docx, .dotx, .docm), Excel (.xlsx, .xltx, .xlsm, .csv — PYQ 2024 Q.87), PowerPoint (.pptx, .ppsx, .potx), Access (.accdb, .mdb).
  • • MS Word: Font dropdown 8–72 pt (Manual 1–1638 pt), Zoom 10%–500%, Max Table Columns = 63, Drop Cap = Default 3 / Max 10 lines, Gutter Margin = Binding space. Shortcuts: Ctrl+H (Replace — PYQ 2021 Q.12), Ctrl+E (Center), Ctrl+= (Subscript), Ctrl+Shift+= (Superscript), Ctrl+5 (1.5 spacing), F7 (Spell Check), Shift+F7 (Thesaurus), Insert key toggles Overwrite mode (PYQ 2023 Q.59).

12–16. Excel Formulas, PowerPoint, Access, Security & Exam Traps

  • • MS Excel: $1,048,576$ Rows $\times 16,384$ Columns (XFD), Zoom 10%–400%. $B$1 = Absolute Ref (PYQ 2017 Q.123, toggle via F4). =AVG() is INVALID (#NAME? — PYQ 2017 Q.173; use =AVERAGE()). COUNT = numbers only; COUNTA = non-empty cells. Shortcuts: F2 (Edit), Alt+= (AutoSum), Alt+Enter (New line in cell), Ctrl+; (Date), Ctrl+Shift+; (Time), F11 (Chart).
  • • PowerPoint & Access: Ctrl+M = New Slide (Ctrl+N = New Deck), F5 = From Slide 1, Shift+F5 = Current Slide, Slide Master = Global logo/fonts. Access .accdb: Short Text max 255 chars; Forms = Input UI, Reports = Print layout.
  • • Cyber Security: Virus needs host file; Worm self-replicates standalone across networks; Trojan disguises as utility (no self-replication); Digital Signature = Signed with Sender's Private Key.
