Quick Revision & Printable One-Page Exam Cheat Sheets

Covers All 19 Required Revision Topics — Click "🖨️ Print / Save PDF" for Exam-Eve Revision

1. OOP Four Pillars & C++ Program Structure

  • Bottom-Up Approach [PYQ 2017 Q.128]: OOP designs classes/objects first, unlike Top-Down procedural C.
  • Encapsulation [PYQ 2017 Q.129 & 2025 Q.22]: Bundling data + methods in a class & hiding data via private.
  • Abstraction: Exposing essential interface operations while hiding implementation details.
  • Inheritance [PYQ 2021 Q.3]: IS-A relationship (`Derived : public Base` in C++, `Child extends Parent` in Java).
  • Polymorphism [PYQ 2017 Q.130]: Compile-time (Overloading) vs Runtime (`virtual` / Dynamic Dispatch).
  • Message Passing [PYQ 2025 Q.34]: myObject.doActivity(args);.

2. Access Specifiers & Constructors vs. Destructors

  • Default Access: C++ class = private; C++ struct = public; Java class = package-private.
  • Constructor Rules [PYQ 2017 Q.191 & 2023 Q.64]: Same name as class, NO return type (not even void), can be overloaded, cannot be virtual, and Friend constructor does NOT exist!
  • Copy Constructor: T(const T &obj) — MUST take reference `&` to prevent infinite recursion!
  • Destructor (`~T()`): Takes 0 args, cannot be overloaded, CAN and SHOULD be virtual in base classes.
  • Execution Order: Constructors run FIFO (Base → Derived); Destructors run LIFO (Derived → Base).

3. Overloading vs. Overriding & Virtual Functions

  • 5 Non-Overloadable C++ Operators: . (dot), .*, ::, ?:, and sizeof (`typeid`).
  • 4 Member-Only Overloadable Operators: =, (), [], and -> (cannot be `friend` functions).
  • Pure Virtual Function & Abstract Class: virtual void f() = 0; makes the class Abstract (cannot instantiate value objects, only pointers/references).
  • C++ vs Java Default Binding: C++ methods are non-virtual by default; Java non-static/non-final/non-private methods are virtual by default!

4. Pointers, Stack vs. Heap, Templates & C++ File Streams

  • new/delete vs malloc/free: new is an operator that calls the Constructor and returns typed `T*`; delete calls the Destructor (`delete[]` for arrays).
  • this Pointer: Type is ClassName* const; absent in static and friend functions [PYQ 2017 Q.192].
  • C++ Exceptions & Templates: try, throw, catch, catch(...); template <typename T> expands at compile time.
  • C++ ``: seekg()/tellg() = input get pointer; seekp()/tellp() = output put pointer.

5. Java JVM/JRE/JDK, 8 Primitives & Inheritance

  • Java Pipeline [PYQ 2021 Q.149]: .java → javac → Bytecode (.class) → JVM (ClassLoader + Verifier + Interpreter/JIT). Bytecode is platform-independent; JVM is platform-dependent!
  • Equations: $\text{JRE} = \text{JVM} + \text{Libraries}$; $\text{JDK} = \text{JRE} + \text{Dev Tools (javac, jar, jdb)}$.
  • 8 Primitives [PYQ 2017 Q.199]: byte (1B) [PYQ 2021 Q.5], short (2B), int (4B), long (8B), float (4B), double (8B), char (2B Unicode), boolean (true/false) [PYQ 2023 Q.54].
  • Octal Trap [PYQ 2023 Q.18]: int[] p = {121, 201, 017}; → p[2] = 15.
  • Java OOP [PYQ 2025 Q.23 & Q.25]: super calls parent constructor/method; protected is inherited; interface fields are public static final.

6. Java Exception Handling & Frequently Confused Traps

  • 10 / 0 vs 10.0 / 0.0 [PYQ 2017 Q.137 & 2025 Q.36]: Integer `10 / 0` throws ArithmeticException; float `10.0 / 0.0` prints Infinity!
  • Multiple Catch Rule [PYQ 2025 Q.36]: Child exception (`ArithmeticException`) MUST appear before parent (`Exception`).
  • Custom Exception [PYQ 2025 Q.33]: `class CustomException extends Exception` passes message via `super(msg)` read by `e.getMessage()`.
  • String Pool Trap: `s1 == s2` checks reference address; `s1.equals(s2)` checks character content; `String` is immutable whereas `StringBuilder` (fast) and `StringBuffer` (synchronized) are mutable.
